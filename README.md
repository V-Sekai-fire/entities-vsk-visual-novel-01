# entities-vsk-visual-novel-01

A short branching noir story written as an interactive-fiction script, with the prompts and drafts that led to it.

## What it is for

`Concept_rpg_novel_06.ink` is the finished story: the player studies a gangster in a rain-soaked bar, gathers clues, and chooses how to approach him. `decisions/` keeps the earlier prompts, drafts and comments.

## Build and run

Any compiler or player for the ink scripting language runs the `.ink` file.
